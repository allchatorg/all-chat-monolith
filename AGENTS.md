# Project conventions

- Always write the product name as `allchat`, in lowercase, including at the
  start of sentences, in headings, UI labels, accessibility text, and documentation.
  The subscription name is `allchat Pro`. Do not uppercase the brand with CSS.
- Preserve existing code identifiers, environment variable names, and external
  API contracts when updating display copy; those are not product branding.
- Use descriptive `feature/` or `fix/` branch names.
- Keep commit messages and pull request descriptions focused on the changes.
  Do not include generated-by notes, tool attribution, or co-author trailers.
